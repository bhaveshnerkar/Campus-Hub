# CampusHub Architecture

## Frontend
React and TypeScript using Vite.

## Backend
Python and FastAPI provide API endpoints and application logic.

## Database
Supabase PostgreSQL stores application data.

## Communication
The frontend communicates with the backend API.
The backend accesses the database through the configured Supabase integration.

## Security
Secrets are stored in local environment variables.
Authentication and database access policies will be documented before implementation.
